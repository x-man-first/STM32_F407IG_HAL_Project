# 设计文档（中文版）

## 概述 ✅
本项目为一个基于 STM32F407 的无传感器/有霍尔传感器 BLDC（无刷直流电机）控制框架的示例程序。代码采用 HAL 层为基础，模块化分层架构，将业务逻辑、硬件抽象、设备驱动分离，易于扩展与维护。

主要目标：
- 提供稳定的电机 6-step霍尔驱动逻辑
- 支持通过 CAN 接收控制指令
- 提供任务 / 模块生命周期管理（初始化/反初始化）
- 定时调度与 IRQ 分割调度（TIM2 负责周期性任务、TIM1 负责 PWM/电机中断）

---

## 功能需求与范围
- CAN 接收 VCU 指令（CANID_VCU_CMD）控制启动/停止、方向与占空比
- PWM 驱动 TIM1 通道用于控制 MOSFET/PWM
- 霍尔传感器（TIM1 霍尔模式）用于转子位置检测，触发 6-step换相
- 键盘输入（KEY）用于本地控制/调试（可选）
- 模块生命周期（Init/DeInit）由 `ModeStateMechanic` 管理

---

## 关键设计决策 ⚙️
- 使用 HAL 驱动库：降低底层寄存器错误；提升可移植性
- 将应用层（ASW）、硬件抽象层（BSW）、设备驱动层（CDD）分离；避免业务逻辑直接调用底层硬件接口
- 通过 `ModeStateMechanic` 管理初始化状态，便于模块注册/注销，支持进入睡眠、故障恢复等状态
- 将中断处理（TIM1）和周期性任务（TIM2）分开，保证关键电机中断响应最小处理时间

---

## 数据流与控制流
1. CAN -> `BSW/CAN/Can.c` 接收消息（HAL CAN RX FIFO 回调） -> 解析并设置 `Bldc_Control_Req` 全局变量
2. 主循环 (main) 调用 `ModeStateMechanic_Main` 在 `Flag_1ms` 触发后处理系统模式与模块生命周期
3. `ModeStateMechanic` 在 `MM_MOTORCONTROL` 状态下，调用 `MotorControl_Control` 读取 `Bldc_Control_Req` 并更新 `bldc_status`，设置 PWM 和运行/停止指令
4. `TIM1` 中断 -> `Motor_Handler_IN_TIM1IRQ` 执行霍尔读取、换相；`PWM_SetDutyCycle` 在主循环/控制函数中被调用

---

## 安全与边界条件
- 在 CAN 解析时做最小有效性检查（例如 ID 匹配 `CANID_VCU_CMD`）
- 仅在 `bldc_status.step_sta` 在 1..6 时才进行换相；异常值将导致停止并置入 STOP 状态
- 禁止在 ISR 中执行阻塞/长时间逻辑；ISR 仅读霍尔并设置状态，复杂逻辑在主循环中处理

---

## 扩展性建议
- 新模块加入：在 `ASW/ModeStateMechanic/src/ModeStateMechanic_InitTask.c` 中为 `MM_InitCfg` 增加入口，并在 `MM_InitStsIndexes` 中添加索引
- 若增加 CAN 命令集，请统一维护 `Can_Cfg.h` 中 CANID 常量，并在 `Can.c` 中对应解析处理
- 若扩展更多 PWM 或 ADC 采样点，在 `BSW/PWM` 中增加通道映射，规范 `PWM_SetDutyCycle` 的平滑过渡策略

---

## 测试要点
- 模拟 CAN 命令下发：验证 `Bldc_Control_Req` 更新和 `bldc_status` 的变化
- 仿真霍尔信号：模拟 6 键序列，测试 `Motor_Handler_IN_TIM1IRQ` 的换相与 PWM 输出
- 验证 ModeStateMechanic 的初始化/反初始化流程：在 `MM_InitReq` 切换时各模块是否正确响应
