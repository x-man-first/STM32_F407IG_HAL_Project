# 接口描述文档（中文版）

本文档列出项目中主要模块的公共接口（函数、全局变量、消息格式），并给出说明与使用注意事项。

---

## 目录索引

- Core: `Core/Src/main.c`
- ModeStateMechanic: `ASW/ModeStateMechanic/*`
- MotorControl: `ASW/MotorControl/*`
- CAN: `BSW/CAN/*`
- PWM: `BSW/PWM/*`
- TIM2: `BSW/TIM2/*`
- Hall: `CDD/Hall/*`
- Key: `CDD/KEY/*`

---

## 主循环入口（Core）

- MCU_Init(void)

  - 执行系统初始化（HAL、SystemClock、GPIO、TIM2、CAN、PWM、key 等），并初始化模式管理
  - 关键文件：`Core/Src/main.c` -> `MCU_Init()`
- MCU_Main(void)

  - 读取定时标志 (`Flag_1ms/10ms/100ms/500ms`) 并派发任务
  - 100ms 调用 `CAN1TX()`，500ms 切换 LED
  - 1ms 调用 `ModeStateMechanic_Main()`

---

## ModeStateMechanic 接口（ASW）

- 头文件路径：`ASW/ModeStateMechanic/include/ModeStateMechanic.h`
- void ModeStateMechanic_Init(void)

  - 初始化 FSM 状态、设置 `MM_InitReq = MM_INIT_REQ_INITIALIZE` 并将 `MM_InitSts[]` 清零为 `MM_INIT_STS_DEINITIALIZED`。
- void ModeStateMechanic_Main(void)

  - 1ms 调度调用，读取输入/管理状态，调用 `MM_InitDeinit()` 以初始化/反初始化子模块，并在 `MM_MOTORCTRL_MODE` 中调用 `MotorControl_Control()`。
- ModeStateMechanic_InitTask.h 中重要项：

  - `MM_InitCfg[]`: 注册模块 `InitStart` / `InitPending` / `DeinitStart` / `DeInitPending` 回调
  - `MM_InitSts[]`: 状态数组
  - `MM_InitReq`: 初始化/反初始化请求

## MotorControl（ASW）

- 头文件路径：`ASW/MotorControl/include/MotorControl.h`
- 数据结构：

  - bldc_status_type: 运行状态
    - run_flag (uint8_t)：运行标志（RUN=1, STOP=0）
    - step_sta (uint8_t)：本次霍尔状态 (1..6)
    - step_last (uint8_t)：上次霍尔状态
    - dir (uint8_t)：方向 (CW/CCW)
    - pwm_duty (uint16_t)：占空比
  - Bldc_Control_Req_type: 控制请求
    - start_stop (uint8_t)
    - CW_CCW (uint8_t)
    - pwm_duty (uint16_t)
- 全局实例（extern）：

  - extern bldc_status_type bldc_status;
  - extern Bldc_Control_Req_type Bldc_Control_Req;
- 函数接口：

  - uint8_t MotorControl_Init(void)
    - 初始化 MotorControl, 停止 PWM, 返回 1 表示初始化成功
  - uint8_t MotorControl_DeInit(void)
    - 反初始化 MotorControl, 停止 PWM, 返回 1 表示成功
  - void MotorControl_Control(void)
    - 主控制入口：读取 `Bldc_Control_Req`、处理键值（可选）、更新 `bldc_status` 并调用 `PWM_SetDutyCycle` 来调整 PWM 值；在启动/停止时切换 PWM 启停
  - void Motor_Handler_IN_TIM1IRQ(void)
    - 在 TIM1 中断里调用的霍尔读/换相处理；代码依赖 `Hallsensor()` 返回 1..6 的值
- 使用注意：

  - 不要在 ISR 中执行阻塞或长时间计算；`Motor_Handler_IN_TIM1IRQ` 仅做换相与必要 runtime check
  - 为新模块或修改 `bldc_status` 时，使用访问器函数保持 ABI 稳定

## PWM（BSW）

- 文件：`BSW/PWM/include/PWM.h` 与 `BSW/PWM/src/PWM.c`
- 外部句柄：`extern TIM_HandleTypeDef htim1;`（TIM1 用于 PWM）
- API：

  - void PWM_Init(void)
  - void PWM_Start(TIM_HandleTypeDef* htim)
  - void PWM_Stop(TIM_HandleTypeDef* htim)
  - void PWM_SetDutyCycle(uint32_t Channel, uint32_t dutycycle)
- 注意：占空比单位与 `htim1` 的周期设置相关，`MotorControl` 使用 `bldc_status.pwm_duty` 设置 `PWM_SetDutyCycle`。

---

## CAN（BSW）

- 文件：`BSW/CAN/include/Can.h`, `BSW/CAN/include/Can_Cfg.h`, `BSW/CAN/src/Can.c`
- 常量（在 `Can_Cfg.h` 中）：

  - CANID_VCU_CMD = 0x000
  - CANID_SYNC = 0x001
- API：

  - void CAN1_Init(void)
  - void CAN1TX(void) -> 发送心跳/同步帧（默认数据 8 字节 `{0x55,0xAA...}`）
  - CAN_Status_Type Get_CAN_Status(void)
- 接收处理

  - `HAL_CAN_RxFifo0MsgPendingCallback` 调用 `can_receive_msg` 读取消息，之后 `CAN_RX_Handle()` 根据 `CANRX_Data.ID` 解析到 `Bldc_Control_Req`：
    - start_stop = bit 0 of Data[0]
    - CW_CCW = bit 1 of Data[0]
    - pwm_duty = bits [8..23] of Data[0] (16 位)
- 发送处理（内部）

  - `can_send_msg(uint32_t id, uint8_t *msg, uint8_t len)` -> 封装标准帧并提交到邮箱

---

## TIM2（BSW）

- 定时器：`MX_TIM2_Init()` -> 1ms tick 用于调度
- Flags（在 `BSW/TIM2/include/TIM2.h`）:
  - `Flag_1ms`, `Flag_10ms`, `Flag_20ms`, `Flag_50ms`, `Flag_100ms`, `Flag_500ms`
- 中断：`TIM2_Handler_IN_IRQ` 在 TIM2 ISR 时被调用，设置 Flags；`Core/main.c` 的主循环在读到 Flag 时清除并处理对应业务

---

## Hall（CDD）

- 文件：`CDD/Hall/include/Hall.h`、`CDD/Hall/src/Hall.c`
- 函数：`uint32_t Hallsensor(void)` -> 返回 1..6 对应霍尔相序
- 用法：在 `Motor_Handler_IN_TIM1IRQ` 中读取

---

## Key（CDD）

- 文件：`CDD/KEY/include/key.h`、`CDD/KEY/src/key.c`
- 函数：
  - `void key_init(void)` -> 初始化按键引脚
  - `uint8_t key_scan(uint8_t mode)` -> 扫描按键；返回 `KEY0_PRES/KEY1_PRES/KEY2_PRES`
- 用法：`MotorControl_Control` 使用 `key_scan` 进行本地调节（加速/减速/停止）

---

## 配置与约定

- 时钟/外设配置：在 `.ioc` 文件自动生成的 `MX_BOX` 实现，主要关注 TIM1/TIM2/CAN1 的配置
- 代码风格：公共 API 放在 `include/`，实现放在 `src/`
- 全局变量：`Bldc_Control_Req` / `bldc_status` 等属于电机领域的公共状态对象，任何新模块访问需谨慎以免破坏 ABI

---

## 示例：通过 CAN 控制电机

发送到 `CANID_VCU_CMD` 的 8 字节 Data（Data[0] low-endian 示例）

- Data[0] bitfields: [0]=start_stop, [1]=CW_CCW, [8..23]=pwm_duty
  例如：
- 启动 + 正转 + 占空比 3000 -> put into Data[0] = 0x00BB 0x0B (依照位域打包)，详见 `BSW/CAN/src/Can.c`
